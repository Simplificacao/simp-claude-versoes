# Simp Claude: instaladores

Aqui ficam só os instaladores do **Simp Claude**, o app da Simplificação para rodar várias sessões do Claude Code
lado a lado. O código fica em outro repositório, privado.

## Instalar
1. Abra [Releases](https://github.com/Simplificacao/simp-claude-versoes/releases/latest) e baixe o `SimpClaude-Setup-<versão>.exe`.
2. Rode o instalador. O Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**.

## Atualizar
A partir da versão 1.5.0 o app se atualiza sozinho: quando houver versão nova, aparece **⬆ Versão X** na barra de
cima. Clique para atualizar na hora ou feche o app quando quiser, e a versão nova é instalada.

Os arquivos daqui são publicados automaticamente pelo GitHub a cada versão. Não envie nada manualmente.
